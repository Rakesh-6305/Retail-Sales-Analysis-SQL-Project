# Retail Sales Analysis (SQL Server Project)

## Project Overview
This project analyzes retail sales data using SQL Server.

## Objectives
- Data cleaning
- Exploratory data analysis
- Business insights

## Tools Used
- SQL Server (SSMS)

## Key Insights
- Top selling category
- Monthly sales trends
- Customer behavior analysis

## Dataset
Retail Sales Dataset (CSV)

## SQL Concepts Used
- SELECT, WHERE
- GROUP BY, ORDER BY
- Aggregate Functions
- CASE Statements

## Conclusion
This project helped in understanding real-world data analysis using SQL.
